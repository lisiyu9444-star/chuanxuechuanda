# 修复适用场景标签色值不一致与可读性问题

## 概述

首页与结果页的「适用场景」标签当前均跟随每日主神色（`themeColor`）渲染，但用户反馈首页标签颜色非常淡、看不清，而结果页相对清晰。经代码排查，两处实现颜色值一致（`borderColor: ${themeColor}33`、`backgroundColor: ${themeColor}0d`、文字 `themeColor`），但组件样式存在差异：首页为 `rounded-xl py-2` 且可能附带描述文字，结果页为 `rounded-full py-1` 无描述文字，导致视觉上首页更淡。

本次修复在保留主神色的前提下，统一两处标签的圆角、间距、透明度，提高半透明背景的对比度，确保首页与结果页视觉一致且清晰可读。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 颜色策略 | 继续使用主神色 `themeColor` | 用户明确要求使用主神色 |
| 透明度调整 | 背景色 alpha 从 `0d`（5%）提升到 `1a`（10%）或更高，边框 alpha 从 `33`（20%）提升到 `66`（40%） | 提高浅色主神色（如金色、黄色）下的可读性 |
| 统一组件 | 同时修改 `outfit-guide-content.tsx` 与 `result/index.tsx` | 当前首页走组件、结果页内联渲染，需两处对齐 |
| 标签样式 | 统一为 `rounded-full py-1 px-3`，移除首页标签的描述文字 | 与结果页截图风格一致，减少视觉面积带来的"淡"感 |

## 功能模块

### 适用场景标签
- 输入：`llmPlan.occasions: string[]`
- 输出：主神色胶囊标签列表
- 字段示例：`['都市通勤', '艺术展览', '下午茶约会']`

## 是否有原型设计

是。设计引导工具已开启，即使本次为样式修复，也先通过原型确认标签视觉样式后再开发。

## 实施步骤

1. **阶段一：原型设计**：加载 `design-canvas` 技能，完成「适用场景」标签在首页与结果页的原型样式确认（主神色、透明度、圆角）。
2. **阶段二：代码开发 - 统一首页场景标签样式**：修改 `src/components/outfit-guide-content.tsx`，将场景标签统一为 `rounded-full py-1 px-3`，移除描述文字，调整主神色透明度使标签更清晰。
3. **阶段二：代码开发 - 统一结果页场景标签样式**：修改 `src/pages/result/index.tsx`，将场景标签样式与首页组件对齐。
4. **阶段二：代码开发 - 验证与构建**：执行 `pnpm validate` 与 `pnpm build`，确保样式类名合规且构建通过。
