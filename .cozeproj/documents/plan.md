# 抖音小程序审核适配 — UI 隐藏方案

## 概述

将小程序中所有命理/运势相关 UI 通过**编译期渠道常量**条件渲染隐藏，使抖音包呈现为纯穿搭推荐工具以通过审核；微信包不受影响，继续展示完整内容。不删除任何代码，微信渠道可随时恢复。本次改动仅涉及前端 3 个页面 + 1 个组件 + 1 个新增常量模块，无后端改动。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 渠道判断 | `process.env.TARO_ENV === 'tt'` 编译期常量 | `build:tt` 产物自动为抖音模式、`build:weapp` 自动为微信模式，随构建命令固话，杜绝"忘改开关导致微信版被误隐藏"的事故；比手动改常量更安全 |
| 常量出口 | 新增 `src/utils/channel.ts`，导出 `IS_DOUYIN` 与 `SHOW_METAPHYSICS = !IS_DOUYIN` | 单一来源，四处改动点统一引用 |
| 隐藏方式 | 条件渲染包裹（`{SHOW_METAPHYSICS && ...}`） | 代码零删除，微信渠道一键恢复；满足"不要删除代码"要求 |
| 与现有开关关系 | 保留服务端 `showBaZiContent`/`showBaziOverview` 机制不动，渠道常量作为更外层条件叠加 | 两套机制正交：服务端开关管运营，渠道常量管审核，互不干扰 |
| 后端接口 | 不改动，仍返回完整八字数据 | 抖音审核以 UI 呈现为准；前端不渲染即可。接口字段裁剪列为可选增强（本期不做） |

## 功能模块

### 1. 渠道常量模块（新增）

`src/utils/channel.ts`：
- `IS_DOUYIN = process.env.TARO_ENV === 'tt'`（编译期注入，构建产物中为字面量，无运行时开销）
- `SHOW_METAPHYSICS = !IS_DOUYIN`（语义化：是否展示玄学内容）

### 2. 首页（`src/pages/index/index.tsx`）

| 区块 | 位置（约） | 抖音模式 |
|------|-----------|---------|
| 顶部档案切换栏 | 页首 | 保留 |
| 幸运指数卡片（气场/事业/桃花/放松/灵感 + 幸运星图 + 描述） | L260 起整块 Card | **隐藏** |
| 今日穿搭卡片（图片 + 解锁按钮） | 中部 | 保留 |
| 穿搭指南（风格主题/幸运色/单品清单/面料建议/适用场景） | OutfitGuideContent | 保留 |
| 穿搭指南内「喜用神分析」Card | outfit-guide-content L110-176 | **隐藏**（见模块 3） |
| 本命穿搭卡片（日主/强弱/用神 + 查看详情） | L387 起整块 Card | **隐藏** |

### 3. 穿搭指南组件（`src/components/outfit-guide-content.tsx`）

- 「喜用神分析」Card（L110-176，含核心用神/喜神/忌神/每日用神）用 `SHOW_METAPHYSICS` 包裹
- 该组件同时被首页与结果页使用；结果页抖音模式下整个组件不渲染（见模块 5），组件内条件只对首页生效
- 其余 Card（风格主题/幸运色/单品清单/面料建议/适用场景）不动

### 4. 加载页（`src/pages/loading/index.tsx`）

- 隐藏底部 4 条步骤列表（正在排列四柱/推演旺缺/分析喜用神/生成穿搭）
- 保留：顶部加载动画、「正在生成中」标题、进度条、个人信息卡片、底部测算人数
- 隐藏后该区间距收紧，不留大面积空白

### 5. 结果页（`src/pages/result/index.tsx`）

- **保留**：顶部穿搭图片区域（平铺图/上身图 Tab 切换 + 图片 + 看视频解锁按钮 + 生成加载态）
- **隐藏**：图片区以下全部内容——八字概览（L1069 起）、喜用神分析、今日穿搭/穿搭指南（outfit-section L1199 起），以及页面其他玄学操作入口
- 实现：抖音模式下图片区以下的 `Unlocked Content` 容器整体不渲染

## 是否有原型设计

否。项目首次开发已完成，本次为现有页面的显隐迭代（设计引导工具规范明确豁免后续小功能迭代）；隐藏后的页面形态即"现有页面去掉指定区块"，无新视觉设计需求。

## 实施步骤

1. **新增渠道常量模块**：创建 `src/utils/channel.ts`，导出 `IS_DOUYIN` / `SHOW_METAPHYSICS`（基于 `TARO_ENV` 编译期判断）。
2. **首页区块隐藏**：`src/pages/index/index.tsx` 用 `SHOW_METAPHYSICS` 包裹幸运指数 Card 与本命穿搭 Card，确认隐藏后布局无空白错位。
3. **穿搭指南喜用神隐藏**：`src/components/outfit-guide-content.tsx` 用 `SHOW_METAPHYSICS` 包裹「喜用神分析」Card，首页穿搭指南其余部分保持展示。
4. **加载页步骤隐藏**：`src/pages/loading/index.tsx` 用 `SHOW_METAPHYSICS` 包裹底部步骤列表区域，收紧残留间距。
5. **结果页只留图片区**：`src/pages/result/index.tsx` 抖音模式下隐藏图片区以下所有内容（八字概览/喜用神分析/今日穿搭），保留平铺图+上身图区域与解锁交互。
6. **双渠道验证**：`pnpm validate` → `pnpm build:tt` 确认抖音包编译通过 → `pnpm build:weapp` 回归确认微信包不受影响；对照显隐清单逐项核对两渠道表现。

## 风险提示

- Loading 页被隐藏的 4 条步骤文案（排列四柱/喜用神等）含玄学词汇，隐藏后加载页不再出现该类词汇；但页面 config 标题「正在生成中」与接口返回字段仍含命理数据。若审核仍被抓包驳回，可选增强：抖音模式下后端裁剪响应中的八字字段（本期不做，待审核结果再定）。
- 分享出去的链接在微信端打开不受影响（分享页为微信生态内行为，微信包正常展示全部内容）。
